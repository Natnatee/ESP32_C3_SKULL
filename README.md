# ESP32_C3_SKULL

## ช่วงกรามที่คาลิเบรตล่าสุด
เปิดสุด **1200 µs (ประมาณ 60°)** / ปิดสนิท **1600 µs (ประมาณ 100°)** ตามผลทดสอบผู้ใช้ Firmware จำกัดช่วงนี้แล้ว GPIO5 เพิ่มพัลส์เพื่อปิดปาก / GPIO6 ลดพัลส์เพื่อเปิดปาก ครั้งละ 50 µs (ประมาณ 5°) ยังคงเริ่มที่ 1500 µs (ประมาณ 90°) ตามเดิม หากปลายทางมีแรงฝืน เสียงคราง หรือร้อน ให้ตัดไฟและเผื่อระยะก่อนชน มุมเป็นคำสั่งประมาณ ไม่ใช่มุมที่อ่านจากเซอร์โว

ข้อมูลด้านล่างเป็นประวัติก่อนจำกัดช่วงตามกรามจริง

## โหมดปัจจุบัน: เริ่มกลางประมาณ 90° ทันที

ตามคำขอผู้ใช้ เริ่มส่ง 1500 µs ที่ 50 Hz ทันทีเมื่อเริ่ม LEDC ไม่รอกดปุ่ม GPIO5 เพิ่ม / GPIO6 ลด ครั้งละประมาณ 5° (50 µs) ช่วงเดิม 1200–1800 µs หรือมุมคำสั่งโดยประมาณ 60–120° ไม่ใช่มุมที่วัดได้ Serial แสดงมุมคำสั่งโดยประมาณ เริ่มที่ 90°

คำเตือน: ผู้ใช้ระบุว่ากรามถอดไม่ได้และเคยวิ่งชนกลไก การตั้ง 90° ไม่รับประกันว่าปลอดภัยหรือช่วยจำกัดความเร็วครั้งแรก ต้องเตรียมตัดไฟเมื่อเริ่มฝืน ยังไม่ทราบสาเหตุอาการเดิมและยังไม่ได้ยืนยันกับฮาร์ดแวร์

### โหมดก่อนหน้า: เปิดเครื่องไม่ส่ง PWM

อัปเดต: ยกเลิกการตั้งกลางอัตโนมัติ เปิดเครื่อง PWM duty = 0 (สัญญาณ LOW) จนกดปุ่ม GPIO5 หรือ GPIO6 ครั้งแรก ซึ่งจะสั่งไปจุดอ้างอิงกลาง 1500 µs (offset 0° ไม่ใช่มุมที่วัดได้) จากนั้นปล่อยแล้วกดอีกครั้งจึงเพิ่ม/ลดประมาณ 5° ถ้าปุ่มถูกกดค้างตอน boot ต้องปล่อยก่อน ห้ามตีความว่าตำแหน่งจริงก่อนเริ่มเป็น 0° เพราะ MG995 ไม่มีสัญญาณ feedback กลับให้ ESP32 การเริ่มส่ง PWM อาจทำให้หมุนเข้ากลางทันที และไม่รับประกันว่าจะไม่มีการกระตุกจากวงจรภายในเซอร์โวตอนเปิดไฟ

### รายละเอียดโหมดปุ่มก่อนปรับการเริ่มต้น

GPIO5 เพิ่ม / GPIO6 ลด ต่อปุ่มแต่ละตัวกับ GND ใช้ INPUT_PULLUP และ debounce 30 ms กดครั้งละประมาณ 5° (50 µs) กดค้างไม่วิ่งซ้ำ เริ่มตรงกลาง 1500 µs หลัง boot 2 วินาที จำกัดช่วงเดิม 1200–1800 µs หรือ offset โดยประมาณ ±30° ไม่ต้องปลดล็อก กดสองปุ่มพร้อมกันไม่ขยับ ต้องปล่อยทั้งสองก่อนกดใหม่ Serial 115200 แสดงปุ่มที่ตรวจพบและ pulse ที่สั่ง เพื่อแยกปัญหาปุ่ม/การเคลื่อนที่ มุมเป็นค่าประมาณจากสมมติฐาน 600 µs = 60° ต้องคาลิเบรตบนเซอร์โวจริง

### โหมด auto sweep ก่อนหน้า (ไม่ได้เปิดใช้แล้ว)

เฟิร์มแวร์ปัจจุบันไม่ใช้ปุ่ม GPIO5/6 หลังเปิดเครื่อง 2 วินาที เริ่ม 1500 µs แล้วกวาด 1200–1800 µs ที่ 50 Hz ทีละ 10 µs ทุก 30 ms พักปลายทาง 700 ms วนต่อเนื่อง สัญญาณ GPIO4 ไฟเซอร์โว 5V และ GND ร่วม ทดสอบโดยถอดจากกลไก หยุดโดยตัดไฟเซอร์โว Serial 115200 แสดง endpoint, uptime และ reset reason เมื่อเริ่ม เพื่อช่วยตรวจอาการรีเซ็ต

### โหมดปุ่มก่อนหน้า (ไม่ได้เปิดใช้ในปัจจุบัน)

ผู้ใช้ยืนยันว่า auto sweep ทำงานแล้ว ปัจจุบัน `src/main.cpp` ใช้ GPIO5 เพิ่ม / GPIO6 ลด โดยแต่ละปุ่มต่อกับ GND (INPUT_PULLUP, Active Low) กดครั้งละ 1% กดค้างไม่วิ่งซ้ำ debounce 30 ms กดสองปุ่มพร้อมกันไม่ขยับ ต้องปล่อยทั้งสองก่อนกดใหม่

หลัง boot ประมาณ 2 วินาที เซอร์โวจะย้ายไปกลาง 50% (1500 µs) โดยอัตโนมัติ ไม่ต้องปลดล็อก จำกัด 0–100% = 1200–1800 µs ที่ 50 Hz ดังนั้น 1% = 6 µs ไม่ใช่ 1% ของมุม 180° รีสตาร์ตกลับ 50% ไม่มี Wi-Fi

ต่อ signal ไป GPIO4, ไฟบวกเซอร์โวไป 5V (ห้ามใช้ 3V3/GPIO), GND ร่วมกับบอร์ด ผู้ใช้ถอดชุด HT7333 ออกในชุดทดสอบนี้ ถ้าใช้ 5V จากบอร์ดผ่าน USB ต้องระวังแหล่งจ่าย/สาย USB จ่ายกระแสไม่พอ หากรีเซ็ต/สั่นให้ทดสอบด้วยแหล่งจ่าย 5V แยกที่รองรับกระแสเซอร์โว โดยต่อ GND ร่วมและไม่เชื่อมไฟบวกของแหล่งจ่ายสองชุดเข้าด้วยกัน

**ทดสอบแบบไม่มีโหลด ถอดจากกราม หยุดโดยตัดไฟเซอร์โว** มุมจริงไม่รับประกันตาม pulse width ตรวจ Serial 115200 เพื่อดูเปอร์เซ็นต์และ pulse width ถ้า log เริ่มใหม่ซ้ำ ให้ตรวจ reset/ไฟตก

เนื้อหาด้านล่างเป็นข้อมูลโหมด manual MG995 ก่อนหน้า ไม่ใช่พฤติกรรมเฟิร์มแวร์ปัจจุบัน

หัวกะโหลก Halloween ขยับกรามด้วย MG995 (180°) เป้าหมายถัดไปคือทำงานเมื่อมีคนเดินผ่าน ปัจจุบันเป็นโหมดทดสอบแรงเซอร์โวด้วยปุ่ม ยังไม่มีระบบตรวจจับคน

## ต่อสาย

| อุปกรณ์ | การต่อ |
|---|---|
| MG995 signal | GPIO4 |
| ปุ่มเพิ่ม | GPIO5 กับ GND |
| ปุ่มลด | GPIO6 กับ GND |
| MG995 V+ | แบตเตอรี่อัลคาไล 4 ก้อน ประมาณ 6V |
| ESP32-C3 3V3 | เอาต์พุต HT7333 3.3V |
| GND | ต่อร่วมกันทั้งหมด |

ปุ่มใช้ INPUT_PULLUP, Active Low ไม่ต้องมีตัวต้านทาน pull-up ภายนอก

## ทดสอบ

1. ครั้งแรกถอดก้านเชื่อมกรามก่อน: ยังไม่ทราบมุมเดิมของเซอร์โว
2. เปิดเครื่อง: ยังไม่ส่ง PWM ไม่สั่งย้ายไปจุดเริ่มต้นอัตโนมัติ
3. กดสองปุ่มค้าง 2 วินาทีเพื่อเปิด PWM ที่ 50% (1500 µs) แล้วปล่อยทั้งสองปุ่ม
4. กดเพิ่ม/ลดครั้งละ 1% กดค้างไม่วิ่งซ้ำ มี debounce 30 ms
5. กดสองปุ่มพร้อมกันขณะทำงานเพื่อหยุด PWM ต้องปล่อยทั้งสองก่อนเริ่มใหม่ โดยเริ่มที่ค่าล่าสุดใน RAM
6. หลังตั้งศูนย์แล้ว ปิดไฟก่อนประกอบก้านกราม และเริ่มทดลองในช่วงแคบๆ อย่าฝืนจุดสุดกลไก

ช่วงทดสอบ 0–100% แมปกับ 1000–2000 µs ที่ 50 Hz แต่ละขั้น = 10 µs **ไม่ใช่การรับประกัน 0–180°** มุมจริงขึ้นกับเซอร์โว ต้องคาลิเบรตก่อนขยายช่วงใน `src/main.cpp` รีสตาร์ตกลับเป็น 50% และปิด PWM เสมอ ไม่มีบันทึกตำแหน่งลง flash

การหยุด PWM ไม่ใช่การตัดไฟและไม่ใช่วงจร emergency stop หากกรามติดขัด มีเสียงคราง หรือเซอร์โวร้อน ให้ตัดไฟทันที เตรียมสวิตช์ตัดไฟเซอร์โวที่เข้าถึงง่าย ห้ามเอานิ้วเข้ากลไกระหว่างจ่ายไฟ และไม่สามารถรับประกันว่าเซอร์โวจะไม่กระตุกตอนเปิดไฟจากพฤติกรรมภายในเซอร์โวได้

## ไฟเลี้ยง

- C 1000 µF คร่อม V+/GND ใกล้เซอร์โว ตรวจขั้วและพิกัดแรงดัน (แนะนำอย่างน้อย 10V)
- MG995 ใช้กระแสสูงเมื่อออกแรง/ติดขัด ถ่านอัลคาไลและกล่องถ่านอาจจ่ายไม่พอ C ไม่ทดแทนแหล่งจ่ายกระแสสูง
- หากหมุนไม่ไหวหรือ ESP รีเซ็ต ให้ตรวจแรงดันตกทั้งรางเซอร์โวและ 3.3V ก่อนสรุปว่าแรงบิดไม่พอ
- ตรวจรุ่น/ผู้ผลิต HT7333 ว่ารับแรงดันแบตเตอรี่ใหม่ กระแส ESP32-C3 และความร้อนได้ ใช้ capacitor อินพุต/เอาต์พุตตาม datasheet ของชิ้นส่วนจริง
- ห้ามต่อ 6V เข้าขา 3V3 หรือ GPIO ของ ESP32 และห้ามเลี้ยงเซอร์โวผ่าน HT7333
- ก่อนเสียบ USB ขณะใช้ไฟภายนอก ให้ตรวจวงจรบอร์ดว่าไม่ backfeed/ให้ regulator สองตัวขับราง 3.3V ชนกัน ถ้าไม่ทราบ ให้แยกไฟภายนอกออกจาก ESP32 ก่อนเสียบ USB

## Build / Upload

```sh
pio run
pio run -t upload
pio device monitor
```

Serial 115200 baud แสดงเปอร์เซ็นต์และ pulse width ทุกครั้งที่เปลี่ยนตำแหน่ง ไม่มี Wi-Fi และไม่ใช้ `secrets.h` แล้ว เก็บไฟล์ secrets เดิมไว้โดยไม่แก้ไข
